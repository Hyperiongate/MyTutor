A note while we're still building. These three doors decide what you see — a student sees only their own work, a parent sees only their child, a teacher sees only the classes under their teacher code. They are not yet security: there are no passwords, so anyone holding a code can open that door. Please don't treat a code as private until real accounts are in place.
